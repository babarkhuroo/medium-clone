# Medium Clone

![screenshot](./public/thumbnail.png)

## About

This is a clone of popular online publishing platform Medium. I've cloned the main page with some dummy posts. You can also navigate to each single posts and add/view comments too.

## Technologies Used

- Next.js 16 (Pages Router)
- React 19
- TypeScript 6
- Tailwind CSS 4
- Sanity CMS (Studio v6)

> The original 2022 version of this project (Next.js 12, React 18, Tailwind 3, Sanity Studio v2) is preserved in the git history and tagged `v1-legacy`.

## Getting Started

Requires Node.js 22.12 or newer.

```bash
# Next.js frontend
yarn install
NEXT_PUBLIC_SANITY_PROJECT_ID=w3qwbs3d yarn dev

# Sanity Studio
cd sanity-medium
yarn install
yarn dev
```
